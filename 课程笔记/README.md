# 课程笔记

这里放各门课的知识点整理。用 Markdown 写，比 Word 快，而且能直接在这个仓库里看。

## 建议的文件命名

```
课程笔记/
├── 高等数学/
│   └── 01-函数与极限.md
├── 大学物理/
├── 无机化学/
├── 材料科学基础/
└── 英语/
```

## 每份笔记建议的结构

```markdown
# 章节名

## 核心概念
（用自己的话写，不要抄书）

## 公式
（写清楚每个符号的含义和单位）

## 典型例题
（题目 + 思路 + 易错点）

## 我的疑问
（没搞懂的地方记下来，问到答案后补上）
```

## 为什么要用自己的话写

抄书等于没写。真正的检验标准是：**合上书，能不能把这节讲给同学听明白**。
写不出来，就是没懂——这个信号很值钱，比考试分数来得早。
